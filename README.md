# Jukebox Simulator

A jukebox simulator built in Python as part of my first-year Computing BSc at the University of Greenwich.


## Features
- View a list of tracks
- e.g. Play tracks
- e.g. Create and update a track list


## Files
- `track_player.py`: The main window, with buttons to view tracks, create a track list and update tracks.
- `track_library.py`: Stores the collection of tracks and functions to look them up.
- `view_tracks.py`: A window that lists all the tracks.
- `create_track_list.py`: A window to build your own playlist.
- `update_tracks.py`: A window to change a track’s rating
- `library_item.py`: A class representing one track (name, artist, rating, play count.
- `font_manager.py`: Sets fonts and styling for the windows.
- `test_library_item.py`: Tests for the LibraryItem class.
